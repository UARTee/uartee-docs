Firmware updates

Use firmware only from a tested, compatible UARTee hardware revision.

Before updatingDisconnect UART targets, save configuration, and verify the exact board revision. A generic STM32 image is not guaranteed to support the matching enclosure or board.

Release procedure

Firmware releases will document the toolchain, target device, linker configuration, boot mode, option bytes, flashing command or utility, and verification steps.

Compatibility

  • Check the supported hardware revisions listed in the firmware tag or release.
  • Do not mix firmware and hardware revisions without a compatibility test.
  • Do not flash build artifacts with missing source, license, or manifest information.
  • Confirm USB enumeration and every intended mode after recovery.
