UARTee / Connection modes

03 / Modes

Connection modes

Choose the routing behavior that matches the bench task.

Dual

Expose two independent UART channels through one USB connection. A host terminal or application can communicate with each target independently, subject to tested firmware behavior.

Share

Make one UART's received data visible on two USB serial ports. The control port owns transmit and receive behavior; the monitor port is read-only for received data.

Tap

Actively forward traffic between two UART devices while exposing each received direction on a separate USB serial port.

Tap is not passive probingThe Tap mode requires firmware forwarding and does not provide electrical isolation or guarantee transparent timing behavior.

Port ownership

USB port names, enumeration order, and assignment can vary by host. A released guide will identify the exact USB descriptors and ownership behavior for each firmware build.
