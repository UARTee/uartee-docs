Getting started

Identify the exact board and firmware revision before connecting UARTee to a target.

Before the first connectionUARTee is in development. Package contents, operating systems, firmware, and tested host configurations will be published with a released hardware revision.

Checklist

  • Identify the board revision printed on the PCB or enclosure.
  • Match the firmware build to that exact revision.
  • Confirm target logic voltage and ground connection.
  • Verify USB cable and host port availability.
  • Start with the documented default mode and serial settings.

First connection

Connect USB to the host, ground the UARTee and target together, then connect only the transmit, receive, and ground signals defined for the selected revision.

Host USB → UARTee → Target UART
USB GND ↔ Target GND

Open a serial terminal only after the host enumerates UARTee and the port ownership for the selected mode is known.
