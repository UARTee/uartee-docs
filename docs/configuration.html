Configuration

Configuration commands and settings will be bound to a released firmware build.

Not published yetEntry method, available settings, persistent behavior, and recovery procedure require firmware validation.

Planned settings

  • Connection mode.
  • Serial baud and framing for supported channels.
  • USB serial identifiers where implementation permits it.
  • Startup mode and explicit reset to defaults.

Recovery principles

A release will provide an obvious recovery path that works after incorrect settings or interrupted configuration. It will identify required buttons, indicators, host tools, and whether physical access is needed.
