Troubleshooting

Separate host enumeration, port ownership, wiring, firmware mode, and target configuration.

USB port is missing

  • Try a known-good data cable and USB port.
  • Check power and status indicators for the exact board revision.
  • Verify the firmware build enumerates as designed.
  • Review host logs rather than assuming the target UART caused the fault.

No received data

  • Confirm target and UARTee share ground.
  • Verify transmit and receive are crossed and match the revision pinout.
  • Confirm baud, stop, parity, and voltage settings.
  • Check that the active mode grants receive ownership to the open USB port.

Data is incomplete or corrupt

Confirm baud and clock behavior, then check the target for flow-control assumptions. Distinguish USB host timing, UARTee firmware buffering, target output, and line-level wiring errors before changing configuration.
